## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 重构破坏自举 | 高 | 每步验证 `make check` |
| 格式化器复杂度高 | 中 | 先实现基础功能，迭代增强 |
| 共享模块接口设计 | 中 | 参考 Rust/Cargo 架构 |
| 构建时间增加 | 低 | 增量构建，缓存中间产物 |
