# 逃逸审计根（tests/verify_unsafe_audit.sh 逐个跑 --escape-list，再按 (kind,file) 取最大值合并）
#
# 为什么要多个根：编译器只导入它用到的模块。只用 `src/main.uya` 一个根时，
# 标准库里 http / websocket / tls / jpeg / kernel / tflm 这些模块根本不会被解析，
# 它们的逃逸口完全没进审计面 —— 「审计过的 unsafe 之外零 UB」这句话也就不成立。
# 下面除第一行外，都是「编译器闭包覆盖不到的逃逸文件」，逐个补进来。
#
# 新增/删除根都会改变基线，需在评审里解释。新写了带逃逸构造的文件而没有被
# 任何根覆盖时，闸门会失败并把它列出来 —— 加到这里即可。
