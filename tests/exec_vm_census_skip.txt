# exec VM 覆盖普查跳过表
#
# 格式：每行一个 tests/ 下的用例文件名（basename，可带 `# 原因` 注释）。
#
# 纪律：
#   1. 只允许登记「在 C99 侧同样不适用/同样失败」的用例——即环境、平台或外部依赖
#      导致的跳过，不是「exec VM 还没实现」。
#   2. 每一条都必须写明原因，并在 C99 侧能复现同样的跳过/失败。
#   3. 目标终态是空表：当 P1~P5 完成后，这里应当只剩平台相关的条目。
#
# 示例（暂未启用，保留格式说明）：
# test_macos_kqueue_only.uya    # 仅 macOS 的 kqueue 用例，Linux 宿主 C99 侧同样跳过

# --- C99 侧同样不适用（宿主链接阶段就失败，无法产生可运行程序） ---
# 这四个用例依赖未定义的外部符号（proc / process_data / pt / c_small_struct_param），
# C99 后端起链接直接 undefined reference 失败，exec VM 侧自然也无从对齐。
